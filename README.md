# Skydrift Ridge Run

Skydrift Ridge Run is an original, offline Canvas 2D chase-flight game. Lift off from the Cinderback airfield, guide the redtail through eight glowing river beacons, manage fuel and hull condition, and bring the plane home.

## Play

Open `game/index.html` in a desktop browser or serve `game/` with any static HTTP server. Enter or click to start. Arrow keys or WASD steer and pitch; Shift increases throttle, Ctrl reduces it. The mouse steers toward the pointer and a click gives a short boost. Press P to pause and R to restart. Fly through each gate in order to score and receive a fuel top-up.

The screenshot states are available with `?shot=start`, `?shot=play`, and `?shot=end`; use `&seed=1` to keep terrain and gates reproducible.
